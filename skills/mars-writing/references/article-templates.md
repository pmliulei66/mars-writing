## 开头变体模板

### 模板 A：数据开场
```
[一个让人惊讶的数据或事实]

今天想跟你聊聊《[书名]》，看看这本书能给我们什么答案。
```

### 模板 B：故事开场
```
[一个简短的个人故事或案例，2-3 句话]

这件事让我开始思考一个问题：[核心问题]。

直到我读了《[书名]》，才找到答案。
```

### 模板 C：金句开场
```
"[一句有冲击力的书中原话]"

今天想跟你聊聊这句话背后的故事——来自《[书名]》。
```

### 模板 D：痛点开场
```
你有没有过这样的经历：[描述一个常见痛点场景]？

我以前也这样，直到读了《[书名]》，才发现问题出在哪里。
```

## 去痕检查清单

写完文章后，用这个清单检查：

- [ ] 没有"此外"、"至关重要"、"深入探讨"、"格局"等 AI 词汇
- [ ] 没有三段式过度排比（不超过 2 个并列项）
- [ ] 没有刻意换词（同义词替换癖）
- [ ] 没有通用积极结论（"让我们一起成长"）
- [ ] 没有谄媚语气（"这个问题问得很好"）
- [ ] 没有协作交流痕迹（"让我们一起探讨"）
- [ ] 句子长度有变化（不是每句都一样长）
- [ ] 有口语感（能直接念出来）
- [ ] 有马尔斯的个人经历（哪怕是改编的）
- [ ] 开头 5 秒内有吸引力
- [ ] 结尾有引导关注
- [ ] 字数在 1500-2000 范围
